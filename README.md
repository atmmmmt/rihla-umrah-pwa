# رِحال — RIHLA | مساعد العمرة PWA

نسخة أولية قابلة للتشغيل بتاريخ 1 نوفمبر 2026، تساعد أفراد مجموعة العمرة على فهم مناطق المسجد الحرام والمسجد النبوي، مشاركة الموقع في حال الضياع، الوصول إلى الفندق، وحفظ نقطة للقاء.

## تشغيل التطبيق

### للتجربة محليًا

نفّذ داخل المجلد:

```bash
python -m http.server 8080
```

ثم افتح `http://localhost:8080`، أو شغّل:

```bash
npx serve .
```

**يجب نشر التطبيق على HTTPS عند استخدامه من الهواتف**؛ GPS وميزات الـPWA لا تعمل عادة على استضافة HTTP عادية أو عند فتح `index.html` مباشرة عبر `file://`.

### النشر

يمكن رفع محتويات هذا المجلد كما هي على استضافة Static HTTPS مثل Cloudflare Pages، Vercel، Netlify، أو الاستضافة الثابتة عبر Hostinger. لا يتطلب خادمًا أو قاعدة بيانات للميزات الموجودة حاليًا.

## تحديث الواجهات والملاحة — 1 نوفمبر 2026

- اعتماد خط **Cairo** في الواجهة والأزرار وطبقات الخريطة عبر Google Fonts عند توفر الشبكة. يظهر خط عربي احتياطي عند تعذر تحميله.
- إضافة بطاقة توجيهات مشي خارجية بتعليمات **يمين / يسار / تابع للأمام / استدر للخلف** مع المسافة إلى المناورة القادمة؛ تُحدّث عند تغير الموقع، بشرط وصول خطوات فعلية من خادم التوجيه التجريبي ودقة GPS مقبولة.
- هذه التعليمات **إرشاد تجريبي وليست ملاحة آمنة معتمدة أو بديلًا عن تعليمات التنظيم**. إذا فشل الخادم، يُستخدم زر خرائط Google.
- صور معاينة الواجهات مصممة بإحداثيات ومسار تمثيليين، ولا تعرض خريطة دقيقة للحرم.

## ما يعمل في النسخة الحالية

- اختيار مكة أو المدينة، وخريطة شارع تفاعلية باستخدام **OpenStreetMap + Leaflet** عند الاتصال بالإنترنت.
- تحديد الموقع المباشر عبر GPS من المتصفح مع دائرة دقة الإشارة، والمتابعة أثناء المشي مع إبقاء التطبيق مفتوحًا.
- قائمة مختصرة بالأبواب الرئيسية والمعالم في كل مدينة مع تنبيه واضح بأن **الإحداثيات التقريبية للبوابات ليست مسحًا هندسيًا معتمدًا**.
- روابط مباشرة إلى **خريطة الهيئة العامة للعناية بشؤون الحرمين** التي توفر الإرشاد داخل الحرمين.
- افتراضيًا فندق **voco Makkah**. يمكن تغيير موقع الفندق بالاسم والإحداثيات ؛ الضغط المطوّل على الخريطة يحفظ نقطة لقاء وليس الفندق. فندق المدينة يحدده المستخدم.
- محاولة رسم مسار مشي خارجي مع إرشادات انعطاف إلى الفندق أو نقطة اللقاء عن طريق خادم توجيه مشاة عام. إن تعذر ذلك، يفتح المستخدم اتجاهات المشي على Google Maps، ولا يظهر خط مستقيم كأنه طريق آمن.
- زر «أنا ضايع» لمشاركة إحداثيات الموقع التقريبية عبر واتساب أو قائمة المشاركة، وتعليمات السلامة العامة. في الطوارئ الحقيقية اطلب مساعدة الجهات الميدانية أو اتصل برقم الطوارئ المحلي المعتمد.
- حفظ نقطة لقاء ومشاركتها يدويًا، وحفظ بيانات الإعدادات في `localStorage` على الجهاز نفسه.
- إمكانية تثبيته PWA مع تخزين واجهة التطبيق الأساسية للعمل بعد تحميلها أول مرة (الخريطة الحية والبلاطات والمسارات تتطلب الإنترنت).

## حدود النسخة الحالية — مهمة جدًا

1. **لا توجد ملاحة موثوقة داخل الحرمين أو بين الطوابق.** GPS لا يكفي لمعرفة الطابق أو البوابة الصحيحة، وقد يضلّل المستخدم داخل المباني. المسارات الداخلية والإغلاقات والتنظيم تُؤخذ من الخريطة **الرسمية الحية** فقط.
2. الدبابيس الخاصة بالأبواب الرئيسية على خريطة الشوارع هي **مواقع توضيحية تقريبية**؛ لا يتم حساب طريق مشي إلى هذه الدبابيس، لأن النقطة الدقيقة غير مثبتة في هذا المشروع.
3. **ليست كل الأبواب** موجودة في فهرس التطبيق. القائمة الكاملة والمرافق والخدمات المتغيرة متاحة في خريطة الهيئة الرسمية. استكمال بيانات جميع المداخل يحتاج مصدر بيانات مكاني مرخص ومحدّث.
4. لا يوجد **تتبع حي للجروب أو لوحة قائد أو مشاركة مستمرة بين الأعضاء**؛ مشاركة الموقع تتم بإذن المستخدم وبخطوة صريحة، والحفظ محلي. هذه الميزة تحتاج خادمًا وقاعدة بيانات، موافقات واضحة، وأمانًا وحماية للخصوصية.
5. GPS يتطلب موافقة صريحة من المستخدم وخدمة تحديد الموقع مفعلة في النظام. قد تكون الدقة منخفضة بين المباني وداخل الحرم.
6. تحديث المسار وإرشادات الانعطاف يعتمد على اتصال دائم بالإنترنت وعلى دقة الموقع وعلى مزود المسارات؛ **لم يتم اختبار المسارات ميدانيًا في مكة أو المدينة**.
7. خادم توجيه المشاة عام وتجريبي، ولا يمكن ضمان استقراره أو استمرار إتاحته. للإطلاق الحقيقي استخدم مزود مدفوع أو خادم توجيه مملوك مع قيود خدمة واضحة.
8. بلاطات OpenStreetMap العمومية لها سياسة استخدام وحدود تحميل. للإطلاق لمجموعة كبيرة تعاقد مع مزود بلاطات مرخص، مع المحافظة على حقوق الإسناد وخصوصية المستخدمين.
9. عند عدم وجود إنترنت، قد تفتح واجهة التطبيق المحفوظة لكن **لا توجد خرائط شوارع دون اتصال مضمونة** ولا ملاحة داخلية دون اتصال.
10. رقم 911 هو رقم عمليات الأمن الموحدة للطوارئ في منطقتي مكة المكرمة والمدينة المنورة؛ لا تستخدمه لاستفسارات إرشادية عادية.

## خارطة تطوير نسخة الإنتاج

1. **بيانات مداخل دقيقة:** عقد/ترخيص أو تكامل رسمي مع منظومة خرائط الحرمين لتحديد الإحداثيات والأبواب الفعالة والطوابق ومسارات ذوي الإعاقة بدقة وبحسب ظروف التشغيل.
2. **الملاحة داخل الحرم:** الاعتماد على نظام الـQR الرسمي أو منظومة ملاحة داخلية مرخصة؛ لا تستخدم GPS وحده لتخمين الدور أو حالة الازدحام.
3. **مجموعة العمرة:** قائد رحلة، رابط دعوة، حضور اختياري، حالات «أنا بخير»، نقاط تجمع ومعالم متفق عليها، موافقة محددة المدة على مشاركة الموقع، وإنهاء التتبع عند انتهاء الرحلة.
4. **دعم دون إنترنت:** حزم خرائط أوفلاين مرخصة، دليل أبواب محمل مسبقًا مع تاريخ تحديث وإظهار أنه قد يصبح قديمًا، وإجراءات فقد الاتصال؛ لا تُعِد بالملاحة الداخلية دون خدمة رسمية.
5. **الاستضافة والأمان:** باك اند Node.js/NestJS + MongoDB أو PostgreSQL، تشفير الاتصالات، سياسة احتفاظ قصيرة للمواقع، معدل تحديث معقول، واستعمال إشعارات Push باشتراك صريح.
6. **تجارب الوصول:** وضع كبار السن بنص كبير وتوجيه صوتي اختياري وواجهات عربية/إنكليزية؛ اختبارات على iOS وAndroid وأجهزة حقيقية في الميدان قبل الاعتماد على التوجيه.

## التقنية

HTML / CSS / JavaScript بسيط وقابل للتطوير، Leaflet 1.9.4، خرائط OSM، Service Worker، Web App Manifest، Geolocation API وWeb Share API. لا توجد مكتبات backend أو أسرار في المشروع.
## حالة المستودع على GitHub

هذه نسخة مصدرية عملية قابلة للتطوير، أُعيد تنظيم ملفات JavaScript وCSS فيها عند الرفع. تشمل الملفات `app.js` و`styles.css` و`index.html` و`manifest.webmanifest` و`service-worker.js` وأيقونة SVG. الأيقونة المتوفرة حاليًا SVG، ويُفضّل توليد أيقونتي PNG بمقاسي 192 و512 بكسل للتحقق من التثبيت على جميع الأجهزة. لم يتم نشر الموقع أو اختبار دقة GPS والمسارات ميدانيًا بعد.
